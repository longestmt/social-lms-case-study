# Social LMS Case Study

A product management presentation by Tyler Longest about the development of Unboxed Technology's social LMS.

The case covers the product and stakeholders, three feature decisions (Admin Portal, Learning Paths, and Rewards), roadmap reviews, and the business outcome. Client names are sanitized where appropriate.

## View

Live presentation: https://longestmt.github.io/social-lms-case-study/

For offline viewing, download `index.html` and open it in a browser. The presentation has no external dependencies.

## Present

- Scroll naturally, use the chapter links, or use the previous/next buttons.
- Use the left/right arrow keys when focus is outside a control.
- Light mode is the default; Dark mode and fullscreen are available in the controls.
- Use the browser's print command for a static version.

## Edit and deploy

Edit `index.html`, then commit and push to `main`. GitHub Pages publishes the repository root. `.nojekyll` serves the standalone HTML without Jekyll processing.

Working drafts and interview preparation notes remain local and are excluded from this repository.
